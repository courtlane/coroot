# Поиск проектов в стиле репозитория без мигания при закрытии

## Why
Поиск и прокрутка списка проектов в `front/src/App.vue` уже работают, но PR уходит в чужой репозиторий и должен выглядеть как код мейнтейнера: минимально и в принятом стиле. Кроме того, при выборе найденного проекта поиск сбрасывается сразу при закрытии меню, и во время анимации закрытия на мгновение показывается полный список проектов.

## What Changes
- Сброс строки поиска переносится из закрытия меню в его открытие: в watcher `projectsMenu` при `v === true` выполняется `this.projectSearch = ''`, ветка `if (!v) { ...; return; }` превращается в ранний выход без сброса. Во время анимации закрытия меню показывает тот же отфильтрованный список, при следующем открытии поле пустое.
- Проверяется, что уже сделанные упрощения сохранены: watcher `filteredProjects` — одна строка `this.$nextTick(this.$refs.projectsMenu?.updateDimensions);` (по образцу `front/src/components/QueryBuilder.vue:102`), обёртка поля поиска — `class="pa-2"` без собственного CSS.
- Ничего нового не добавляется: без прокрутки к активному проекту (решение человека), без общих хелперов, без изменения `onProjectSearchKeydown` и логики фокуса.
- История ветки: в коммиты не попадают `openspec/*` и `front/front_test.go`; итоговый diff относительно upstream `6927e8f` содержит только `front/src/App.vue`.

## Impact
- Спецификации: `project-switcher` (ADDED — поведение поиска при закрытии/открытии меню).
- Код: только `front/src/App.vue` (watcher `projectsMenu`, проверка watcher `filteredProjects` и обёртки `pa-2`).
- Образцы стиля (не менять): `front/src/components/QueryBuilder.vue:102`, `front/src/views/Search.vue`.
- Git: ветка `purpleflow/dorabotat-realizatsiyu-spiska-0e76`, база upstream `6927e8f`.

## Invariants
- Изменён только код, добавленный после `4a46a57`; строки, существовавшие в `6927e8f`, не тронуты.
- Тело метода `onProjectSearchKeydown` побайтно совпадает с текущим.
- Во время анимации закрытия меню после клика по найденному проекту список не меняется на полный.
- При каждом открытии меню поле поиска пустое и показан полный список проектов, фокус ставится в поле поиска как раньше.
- При запросе, сильно сокращающем список, меню остаётся прижатым к кнопке «Project»; после закрытия и повторного открытия меню появляется на обычном месте.
- Пункт «new project», надпись «no matching projects», Escape/Tab/Ctrl+K работают как раньше.
- `git diff 6927e8f --stat` показывает только `front/src/App.vue`; `openspec/*` и `front/front_test.go` не входят в коммиты этой задачи.
