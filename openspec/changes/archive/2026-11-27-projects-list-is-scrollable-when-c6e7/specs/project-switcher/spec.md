## ADDED Requirements

### Requirement: Поиск проекта по названию
Если проектов больше 7, меню выбора проекта в боковой панели SHALL показывать над списком проектов поле поиска, которое фильтрует список по регистронезависимому вхождению введённой строки в название проекта. При 7 и менее проектах поле MUST NOT показываться. Ввод в поле и клик по нему MUST NOT закрывать меню, а запрос MUST сбрасываться при закрытии меню. Пункт «new project» MUST оставаться видимым независимо от запроса.

#### Scenario: Фильтрация списка
- **WHEN** проектов больше 7, пользователь открывает меню «Project» и вводит «TEST1»
- **THEN** в списке остаются только проекты, в названии которых есть «test1» без учёта регистра, меню остаётся открытым, а «new project» виден внизу

#### Scenario: Нет совпадений
- **WHEN** пользователь вводит строку, которой нет ни в одном названии проекта
- **THEN** вместо проектов показывается неактивный пункт «no matching projects»

#### Scenario: Выбор найденного проекта и повторное открытие
- **WHEN** пользователь кликает по найденному проекту, а потом снова открывает меню «Project»
- **THEN** открывается обзор выбранного проекта, меню закрывается, а при повторном открытии поле поиска пустое и показан полный список

#### Scenario: Проектов мало
- **WHEN** проектов 7 или меньше и пользователь открывает меню «Project»
- **THEN** поле поиска не показывается и меню выглядит как раньше
