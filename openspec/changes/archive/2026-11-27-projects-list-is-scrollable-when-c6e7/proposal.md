# Поиск по названию в меню выбора проекта

## Why
Когда проектов много, найти нужный в прокручиваемом меню «Project» приходится глазами. Простое поле поиска сверху меню, фильтрующее список по названию, решает это малым изменением одного файла фронтенда.

## What Changes
- В `front/src/App.vue` в меню «Project» над прокручиваемым блоком `.projects` добавить компактное поле `v-text-field` (dense, `hide-details`, `clearable`, иконка `mdi-magnify`, placeholder `search`), только если проектов больше 7 (константа в коде).
- Новое поле данных `projectSearch` (имя `search` уже занято диалогом «Go to…») и вычисляемое свойство `filteredProjects`: регистронезависимый поиск подстроки в `p.name`; при пустом запросе — все проекты в прежнем порядке.
- `v-for` в блоке `.projects` идёт по `filteredProjects`; если ничего не нашлось — неактивный пункт «no matching projects».
- Клики и нажатия клавиш в поле не закрывают меню (`@click.stop`, `@keydown.stop` кроме Esc — Esc по-прежнему закрывает меню).
- Меню получает `v-model="projectsMenu"`; при закрытии меню запрос сбрасывается, при открытии фокус ставится в поле поиска (если оно показано).
- Бэкенд, API и остальные меню не меняются.

## Impact
- Затронутые спецификации: `project-switcher` (ADDED требование про поиск).
- Файлы: `front/src/App.vue` — блок `<v-menu v-if="user" dark right offset-x tile>` с `<div class="projects">` (строки ~87–112), `data()` (~строка 280), `computed` (рядом с `projects()`, ~строка 306), `watch`, `<style scoped>` в конце файла.
- Фронтенд встраивается в бинарник через `go:embed` из `static/` (`main.go`); для проверки нужна сборка фронта (`cd front && npm run build-dev`) или `DEVELOPER_MODE=true`.

## Invariants
- При 7 и менее проектах меню выглядит и работает как раньше: поля поиска нет.
- При пустом запросе показываются все проекты в прежнем порядке; список по-прежнему прокручивается, «new project» виден внизу без прокрутки.
- Клик по найденному проекту ведёт на `overview` этого проекта и закрывает меню; клик/ввод в поле поиска меню не закрывает.
- После закрытия и повторного открытия меню запрос пуст и виден полный список.
- «new project» показывается только пользователям без `readonly` и не зависит от запроса; «no projects available» — только readonly-пользователю без проектов.
- Горячая клавиша Ctrl/Cmd+K и диалог «Go to…» (поле `search`) работают как раньше.
- Бэкенд, API и сохранённые данные не затрагиваются.
