# Прокрутка списка проектов в боковом меню

## Why
Когда проектов много, выпадающее меню выбора проекта в боковой панели (`v-menu` в `App.vue`) не помещается на экран и обрезается без полосы прокрутки, так что часть проектов и пункт «new project» становятся недоступны.

## What Changes
- Ограничить высоту меню выбора проекта атрибутом `max-height` у существующего `v-menu` (Vuetify 2 сам включает `overflow-y: auto` у `.v-menu__content`), чтобы при переполнении появлялась вертикальная прокрутка.
- Других изменений разметки, стилей, логики и API нет — правка в одну строку.

## Impact
- Затронутые спецификации: `project-switcher` (новая).
- Файлы: `front/src/App.vue` — тег `<v-menu v-if="user" dark right offset-x tile>` перед списком `projects` (около строки 87).

## Invariants
- При небольшом числе проектов меню выглядит и ведёт себя как раньше: та же ширина, позиция справа от пункта «Project», без лишней полосы прокрутки.
- Клик по проекту по-прежнему переходит на `overview` выбранного проекта и закрывает меню.
- Пункт «new project» показывается только пользователям без `readonly`, «no projects available» — только readonly-пользователю без проектов; при длинном списке оба остаются достижимы прокруткой.
- Остальные меню боковой панели (пользователь/тема, помощь) не меняются.
- Бэкенд, API и сохранённые данные не затрагиваются.
