# Прокрутка проектов и закреплённый пункт «new project»

## Why
При большом числе проектов меню выбора проекта в боковой панели по-прежнему уходит за нижний край экрана без полосы прокрутки, и пункт «new project» в конце списка не виден. Нужно, чтобы прокручивался только список проектов, а «new project» всегда оставался видимым внизу меню.

## What Changes
- В `front/src/App.vue` обернуть элементы `v-for="p in projects"` внутри меню «Project» в один `<div>` с ограниченной высотой (`max-height: 70vh`) и `overflow-y: auto` (класс в существующем `<style scoped>`), чтобы прокручивался только список проектов.
- Пункты «new project» и «no projects available» оставить как есть, ниже прокручиваемого блока, — они всегда видны без прокрутки.
- Убрать добавленный ранее атрибут `max-height="80vh"` у этого `v-menu`, чтобы не получить две вложенные полосы прокрутки.
- Других изменений разметки, логики, API и бэкенда нет.

## Impact
- Затронутые спецификации: `project-switcher` (MODIFIED).
- Файлы: `front/src/App.vue` — `<v-menu v-if="user" dark right offset-x tile max-height="80vh">` и вложенный `<v-list dense class="pa-0">` (строки ~87–110), блок `<style scoped>` в конце файла.
- Фронтенд встраивается в Go-бинарник через `go:embed` из `static/` (`main.go`), поэтому для проверки нужна свежая сборка фронта (`cd front && npm run build-dev` или `npm run build`) и перезапуск/пересборка Coroot либо `DEVELOPER_MODE=true`. Скриншот из задачи, судя по высоте меню больше 80vh, сделан на сборке без прошлой правки.

## Invariants
- При небольшом числе проектов меню выглядит как раньше: без полосы прокрутки, та же ширина, позиция справа от пункта «Project».
- При длинном списке меню не выходит за пределы окна, список проектов прокручивается до последнего проекта, а «new project» виден без прокрутки.
- «new project» показывается только пользователям без `readonly`; «no projects available» — только readonly-пользователю без проектов.
- Клик по проекту по-прежнему ведёт на `overview` этого проекта и закрывает меню; клик по «new project» ведёт на `project_new`.
- Остальные меню боковой панели (пользователь/тема, помощь) и свёрнутый режим панели не меняются.
- Бэкенд, API и сохранённые данные не затрагиваются.
