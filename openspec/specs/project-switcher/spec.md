## Requirements

### Requirement: Сброс поиска проектов при открытии меню
Меню выбора проекта SHALL сбрасывать строку поиска при открытии, а не при закрытии, чтобы во время анимации закрытия отображался тот же отфильтрованный список.

#### Scenario: Выбор найденного проекта
- **WHEN** пользователь вводит запрос в поле поиска и кликает по найденному проекту
- **THEN** меню закрывается, и во время анимации закрытия список проектов остаётся отфильтрованным

#### Scenario: Повторное открытие меню
- **WHEN** пользователь снова открывает меню проектов после поиска
- **THEN** поле поиска пустое, показан полный список проектов и фокус находится в поле поиска

### Requirement: Положение меню при фильтрации
Меню выбора проекта MUST пересчитывать свои размеры при изменении отфильтрованного списка, оставаясь прижатым к кнопке «Project».

#### Scenario: Запрос сильно сокращает список
- **WHEN** пользователь вводит запрос, после которого остаётся один-два проекта
- **THEN** меню остаётся прижатым к кнопке «Project»

#### Scenario: Закрытие и повторное открытие
- **WHEN** пользователь закрывает меню после фильтрации и открывает его снова
- **THEN** меню появляется на обычном месте
